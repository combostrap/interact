## IDE Debugger

Next to the log as debugger tool, you can start a debug session with a `node` configuration (not `npm`)

For the docs site, there is already a [run configuration](../idea/runConfigurations/Site%20Start.run.xml)

Example:

```bash
src/interact/cli/cli.ts start --confPath=/home/user/code/project
src/interact/cli/cli.ts build --confPath=/home/user/code/project
```
